# MSR-CapNet - Presentation Summary (2 Slides)

## 📊 SLIDE 1: Architecture Overview & Key Components

### 🎯 **Problem & Solution**
**Challenge**: Generate accurate text descriptions for satellite/aerial images despite:
- Scale variation (objects at different sizes)
- Complex scenes (similar-looking regions)
- Limited domain vocabulary

**Solution**: MSR-CapNet = Multi-Scale Region-Aware Captioning Network

---

### 🏗️ **Architecture (3 Stages)**

```
┌─────────────────────────────────────────────────────────────┐
│ STAGE 1: Multi-Scale Feature Extraction                     │
├─────────────────────────────────────────────────────────────┤
│ • ResNet-101 + Swin Transformer (hybrid backbone)           │
│ • RPN (Region Proposal Network) - finds important regions   │
│ • FPN (Feature Pyramid Network) - handles scale variation   │
│   └─ 4 levels (P2-P5): small objects → large scenes        │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ STAGE 2: Adaptive Attention Mechanism                       │
├─────────────────────────────────────────────────────────────┤
│ • Spatial Attention - focuses on important locations        │
│ • Channel Attention - emphasizes relevant features          │
│ • Gated Fusion - balances both (learnable λ ≈ 0.5)         │
│   └─ Dynamic focus: high altitude → semantics / low → detail│
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ STAGE 3: Caption Generation                                 │
├─────────────────────────────────────────────────────────────┤
│ • Topic-Sensitive Word Embeddings (300-D, trained on RSICD) │
│ • Graph Neural Network - models region relationships        │
│ • Transformer Decoder - generates caption token-by-token    │
└─────────────────────────────────────────────────────────────┘
```

### 🔑 **Key Innovations**
1. **Hybrid CNN+Transformer** backbone for local+global features
2. **Adaptive attention** dynamically balances spatial & channel focus
3. **Domain-specific embeddings** for remote sensing vocabulary
4. **Two-phase training**: Supervised (50 epochs) → Reinforcement Learning (10 epochs)

# CRSR - Presentation Summary (2 Slides)

## 📊 SLIDE 1: Architecture Overview & Key Components

### 🎯 **Problem & Solution**
**Challenge**: Two-stage RSIC methods using pre-trained detectors/classifiers are limited by:
- Pre-defined semantic labels (can't capture diverse RSI details)
- Poor integration between auxiliary tasks and captioning
- Lack of semantic refinement (misleading information)

**Solution**: CRSR = Cross-Modal Retrieval + Semantic Refinement

---

### 🏗️ **Architecture (3 Main Modules)**

```
┌──────────────────────────────────────────────────────────┐
│ MODULE 1: Cross-Modal Retrieval (CLIP-based)            │
├──────────────────────────────────────────────────────────┤
│ • Fine-tuned CLIP model for image-text matching          │
│ • Retrieves top-K relevant sentences from sentence pool  │
│ • Mask strategy: focuses on semantic-relevant words      │
│ • Words decomposed from retrieved sentences = Primary    │
│   semantic information                                   │
└──────────────────────────────────────────────────────────┘
                            ↓
┌──────────────────────────────────────────────────────────┐
│ MODULE 2: Semantic Refinement                            │
├──────────────────────────────────────────────────────────┤
│ • Masked Cross-Attention (Nc=3 Transformer blocks)       │
│   └─ Filters misleading/conflicting words                │
│   └─ Handles contradictory info (e.g., "plane" vs        │
│       "planes")                                          │
│ • Random masking of semantic-irrelevant words            │
│ • Output: Refined semantic tokens (V̅ₛ)                  │
└──────────────────────────────────────────────────────────┘
                            ↓
┌──────────────────────────────────────────────────────────┐
│ MODULE 3: Transformer Mapper + Decoder                   │
├──────────────────────────────────────────────────────────┤
│ Transformer Mapper (Nr=6 blocks):                        │
│ • Projection layer: vᵢ → k=10 visual vectors            │
│ • Learnable queries (Q): predict omitted words           │
│ • Hungarian matching for query-word alignment            │
│                                                          │
│ Cross-Modal Decoder (Nd=6 Transformer blocks):           │
│ • Inputs: Visual tokens (Ṽᵢ) + Query tokens (Q̃ᵢ) +     │
│           Refined semantic tokens (Ṽₛ)                  │
│ • Gated fusion: γzₜ + (1-γ)attₜ (balances visual +      │
│   semantic)                                              │
│ • Multi-head attention over image & semantic features    │
└──────────────────────────────────────────────────────────┘
```

### 🔑 **Key Innovations**
1. **CLIP-based retrieval** instead of pre-trained detectors → no label constraints
2. **Masked attention** for semantic refinement → filters contradictions
3. **Learnable queries** predict missing semantic info beyond retrieval
4. **Three-loss training**: Lw (word filtering) + LQ (query prediction) + Lc (caption)

---

# PCSFTr - Presentation Summary (2 Slides)

## 📊 SLIDE 1: Architecture Overview & Key Components

### 🎯 **Problem & Solution**
**Challenge**: Existing RSIC methods have limitations:
- Pre-trained detectors/classifiers constrained by predefined labels
- Spatial-domain focus → miss semantic info in channel domain
- Simple fusion (concatenation/summation) → insufficient for complex scenes
- Same objects appear differently across scenes (dense vs. sparse residential)

**Solution**: PCSFTr = Positional-Channel Semantic Fusion Transformer

---

### 🏗️ **Architecture (Multi-Stage Encoder-Decoder)**

```
┌────────────────────────────────────────────────────────────┐
│ STAGE 1: Scene Classification Pre-training                 │
├────────────────────────────────────────────────────────────┤
│ • ResNet trained on scene classification task               │
│ • Learn scene-level semantic information (dense/sparse)     │
│ • Extract visual features F ∈ R^(C×H×W)                    │
│   └─ C=512, H=W=7 (most datasets), 12×12 (Sydney)         │
└────────────────────────────────────────────────────────────┘
                            ↓
┌────────────────────────────────────────────────────────────┐
│ STAGE 2: Encoder - PCMSA Block (Ne=layers)                 │
├────────────────────────────────────────────────────────────┤
│ Position Multi-Head Self-Attention (PMSA):                 │
│ • Flatten F → Fs ∈ R^(C×N), N=H×W=49                      │
│ • Transpose Fs → Fp ∈ R^(N×C)                              │
│ • Q,K,V = Fp·Wq, Fp·Wk, Fp·Wv                              │
│ • Attention(Q,K,V) = softmax(QK^T/√dk)·V                   │
│ • Split by hp heads → P ∈ R^(N×C) (positional features)   │
│                                                             │
│ Channel Multi-Head Self-Attention (CMSA):                  │
│ • Q=K=V = Fs (no projection)                               │
│ • Split by hc heads → C ∈ R^(C×N) (channel features)      │
│                                                             │
│ Feature Fusion (FF) Block:                                 │
│ • Reshape P,C → p,c ∈ R^(C×H×W)                            │
│ • Initial fusion: z = p + c                                │
│ • Local context: L(z) = BN(Conv2(ReLU(BN(Conv1(z)))))     │
│ • Global context: G(z) = BN(W2(ReLU(BN(W1(GAP(z))))))     │
│ • Attention weight: M(z) = σ(L(z) ⊕ G(z))                  │
│ • Final fusion: Ff = M(z)⊗p + (1-M(z))⊗c                   │
│   └─ Bottleneck C→C/r→C (reduces params)                   │
└────────────────────────────────────────────────────────────┘
                            ↓
┌────────────────────────────────────────────────────────────┐
│ STAGE 3: Decoder (Nd=layers)                               │
├────────────────────────────────────────────────────────────┤
│ Semantic Mask Multi-Head Attention (SMaskMHA):             │
│ • Word embedding: Ew = Embedding(w) ∈ R^(m×C)              │
│ • Global semantic: g = GAP(Fe) ∈ R^(C×1)                   │
│ • Q = Ew·Wq, K,V = [g^T, Ew]·Wk,v                          │
│   └─ Concatenates global info with word sequence           │
│ • Masked attention prevents future word leakage            │
│                                                             │
│ Cross-Modal Multi-Head Attention (CrossMHA):               │
│ • Q = FSM·Wq (from SMaskMHA output)                        │
│ • K,V = Fe^T·Wk,v (from encoder features)                  │
│ • Achieves image-text cross-modal interaction              │
│                                                             │
│ Output: Linear → Softmax → Word prediction                 │
└────────────────────────────────────────────────────────────┘
```

### 🔑 **Key Innovations**
1. **Dual-domain attention**: PMSA (spatial) + CMSA (channel) → captures position AND channel dependencies
2. **Intelligent fusion**: FF block with local/global context → better than simple concatenation/summation
3. **Scene pre-training**: ResNet learns scene semantics (dense vs. sparse residential)
4. **Global semantic injection**: Decoder uses GAP(Fe) to guide word generation

---

---

### ✅ **Strengths**
- **Dual-domain learning**: Spatial + channel → comprehensive semantic extraction
- **Intelligent fusion**: FF block > simple concatenation (proven in ablation)
- **Scene-aware**: ResNet pre-training captures scene-level semantics
- **Best on large datasets**: Strongest on UCM-Captions & NWPU-Captions

### ⚠️ **Limitations**
- **Sydney dataset**: -13.7% CIDEr vs. Deformable-T (sequence length 49→144)
- **Multi-scale weakness**: Only uses ResNet final layer (large receptive field)
  - Misses small objects like "scattered houses", "small tennis court"
- **SPICE performance**: Lags BITA by 6.8%-11.2% on RSICD/NWPU
- **Single-scale features**: No multi-scale fusion like FPN

### 📊 **Example Output**

**Novel words** (purple): Accurate scene classification  
**Missed words** (red): "small" (scale issue), "scattered" (multi-scale problem)

---

### 🔬 **Unique Technical Details**

**Bottleneck Design in FF Block:**
- Channel reduction: C → C/r → C (r is reduction ratio)
- Reduces parameters while maintaining expressiveness
- Applied in both L(z) and G(z) branches

**Global Semantic Injection in Decoder:**
- g = GAP(Fe) extracts image-level semantics
- Concatenated: K,V = [g^T, Ew] (adds 1 token to sequence)
- First cross-modal interaction before CrossMHA

---

**Key Takeaway**: PCSFTr excels on **medium-large datasets** with **dual-domain attention** but needs **multi-scale improvements** for small objects! 🎯  
# TSFE - Presentation Summary (2 Slides)

## 📊 SLIDE 1: Architecture Overview & Key Components

### 🎯 **Problem & Solution**
**Challenge**: Single-stage feature enhancement methods have limitations:
- Simple concatenation → imbalanced channel distribution (small objects overlooked)
- No positional relationship modeling between image regions
- ViT's flattening disrupts structural information + high computational cost
- Single-scale global features insufficient for multi-object scenes
- Direct fusion of image/text features → semantic mismatch

**Solution**: TSFE = **Two-Stage Feature Enhancement**

---

### 🏗️ **Architecture (3 Main Modules)**

```
┌─────────────────────────────────────────────────────────────┐
│ MODULE 1: Adaptive Multi-Scale Feature Fusion (AMFF)       │
├─────────────────────────────────────────────────────────────┤
│ Swin Transformer Backbone:                                  │
│ • Extract features: {F₁, F₂, F₃, F₄} = ST(I, θ)           │
│ • Skip F₁ (low-level), use F₂, F₃, F₄                     │
│                                                             │
│ Multi-Scale Concatenation:                                 │
│ • F = concat(F₂, F₃, F₄) [channel dimension]              │
│                                                             │
│ Channel Attention (SENet):                                 │
│ • Fs = SENet(F, θ) → adaptive channel weights              │
│ • Handles imbalanced channel distribution                  │
│                                                             │
│ Weighted Linear Fusion:                                    │
│ • Vlocal = w₁·F₄ + w₂·Fs (w₁, w₂ trainable)               │
│   └─ F₄: larger receptive field features                   │
│                                                             │
│ Global Feature Extraction:                                 │
│ • Vglobal = GAP(Vlocal) = (1/H×W) Σᵢ Σⱼ Vlocal[i,j]      │
│   └─ Contains multi-scale scene semantics                  │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ MODULE 2: Local Feature Squeeze & Enhancement (LFSE)       │
├─────────────────────────────────────────────────────────────┤
│ Efficient Multi-Head Attention:                            │
│ • Project Vlocal → q, k, v                                 │
│ • Horizontal squeeze: q⁽ʰ⁾ = (1/W)·avg(q) → (H, C)       │
│ • Vertical squeeze: q⁽ᵛ⁾ = (1/H)·avg(q) → (W, C)         │
│ • Attention: Va = Σ softmax(q⁽ʰ⁾ᵀk⁽ʰ⁾)v⁽ʰ⁾ +              │
│                   Σ softmax(q⁽ᵛ⁾ᵀk⁽ᵛ⁾)v⁽ᵛ⁾               │
│   └─ Avoids full-sequence modeling (H×W → H+W)            │
│                                                             │
│ Convolution-Based Detail Enhancement:                      │
│ • Vu = BN(Dwconv[concat(q,k,v)]) [3×3 depthwise conv]     │
│ • Vs = Va × BN(Conv[Vu]) [compensate lost details]        │
│                                                             │
│ Local Attention Module (N soft attentions):                │
│ • Construct N weighting maps: α̅[n,i,j] = (1/C)Σ Vs·w[n]  │
│ • Scaled weights: α[n,i,j] = exp(α̅)/Σexp(α̅)              │
│ • Aggregate: V'local[n,k] = (1/H×W) Σᵢ Σⱼ Vs[i,j,k]·α    │
│   └─ Restores long-distance spatial correlations           │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ MODULE 3: Feature Interaction Decoder (FID)                │
├─────────────────────────────────────────────────────────────┤
│ Attention-Based LSTM Decoder:                              │
│ • Similarity: at = (V'localᵀ · W · ht-1) / √d              │
│ • Attention weights: αt = softmax(at)                      │
│ • Weighted features: vt = αt * V'local                     │
│                                                             │
│ Global-Text Feature Interaction:                           │
│ • xt = concat[vt, MLP(Vglobal, st-1)]                      │
│   └─ Vglobal: multi-scale global semantics                 │
│   └─ st-1: previous word embedding                         │
│   └─ MLP: aligns image/text features                       │
│                                                             │
│ LSTM Gates:                                                 │
│ • it = σ(Wi[xt, ht-1] + bi) [input gate]                  │
│ • ft = σ(Wf[xt, ht-1] + bf) [forget gate]                 │
│ • ot = σ(Wo[xt, ht-1] + bo) [output gate]                 │
│ • ct = ft⊙ct-1 + it⊙tanh(Wc[xt, ht-1] + bc) [cell state] │
│ • ht = ot⊙tanh(ct) [hidden state]                          │
└─────────────────────────────────────────────────────────────┘
```

### 🔑 **Key Innovations**
1. **Two-stage enhancement**: Stage 1 (multi-scale) → Stage 2 (positional relations)
2. **Squeeze-based attention**: H×W complexity → H+W (horizontal + vertical squeeze)
3. **Dual detail recovery**: Conv-based kernel + local attention module
4. **Fine-tuning task**: Aligns Vglobal with GloVe sentence embeddings pre-training
5. **Global feature in decoder**: Multi-scale Vglobal guides word generation

### 📊 **Unique Technical Details**

**Squeeze Operation Efficiency:**
- Traditional attention: O(H²W²) complexity
- Horizontal + vertical squeeze: O(H²C + W²C) ≈ O(HW·C)
- **Dramatic reduction** when H×W >> C

**Fine-Tuning Task Design:**
```
SmoothL1(Vglobal, GloVe_avg(sentence))
• GloVe_avg = (1/T) Σₜ GloVe(wordₜ)
• Aligns visual ↔ textual feature spaces
• Multi-label approach (vs. MGTN's single-label)
```

**Dual Loss Training:**
- L₁ (word-level): smoothL1(êₜ, eₜ)
- L₂ (sentence-level): smoothL1((1/T)Σêₜ, (1/T')Σeₜ)
- **Continuous embeddings** (no softmax) → captures global similarity

### ✅ **Strengths**
- **Two-stage design**: Multi-scale → positional relations (systematic approach)
- **Efficient attention**: Squeeze-based reduces O(H²W²) → O(HW·C)
- **Detail preservation**: Conv kernel + local attention compensates structural loss
- **Aligned global features**: Fine-tuning task bridges image/text gap
- **Best on large datasets**: +15.7% BLEU-4 on RSICD (10,921 images)

### ⚠️ **Limitations**
- **Mixed performance on small datasets**: 
  - UCM: -5.9% CIDEr vs. MGTN
  - Sydney: -1.6% CIDEr vs. MGTN
  - Possibly overfits to large-scale scenarios
- **METEOR lag**: -3.7% on RSICD (synonym/stem matching issue?)
- **Squeeze operation trade-off**: Gains efficiency, loses some fine details
- **Computational overhead**: Two-stage pipeline vs. single-stage methods
- **No explicit object detection**: Unlike CRSR's retrieval or PCSFTr's scene classification

```
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│ STAGE 2: Cross-Modal Fusion                │
│ • Image features ⊗ Retrieved templates     │

│ • Fuses visual + textual semantics         │
└─────────────────────────────────────────────┘
                    ↓

```

### **2️⃣ MSR-CAPNet: Multi-Scale Relational Context**
```
┌────────────────────────────────────────────────┐
│ MULTI-SCALE FEATURE EXTRACTION              │
│ • ResNet backbone → {C3, C4, C5}              │
│ • FPN-like fusion: P3, P4, P5                 │
│ • Multi-scale grid features (different strides)│
└────────────────────────────────────────────────┘
                    ↓
┌────────────────────────────────────────────────┐
│ CONTEXT-AWARE PROCESSING                     │
│                                                │
│ ┌──────────────────────────────────────────┐ │
│ │ Intra-Scale Context (ISC):                │ │
│ │ • Self-attention within each scale        │ │
│ │ • Captures spatial dependencies           │ │
│ │ • Formula: ISC(Pi) = softmax(QiKi^T)Vi    │ │
│ └──────────────────────────────────────────┘ │
│                                                │
│ ┌──────────────────────────────────────────┐ │
│ │ Inter-Scale Context (IEC):                │ │
│ │ • Cross-scale attention {P3, P4, P5}      │ │
│ │ • Scale interaction modeling              │ │
│ │ • Weighted fusion: α3·P3 + α4·P4 + α5·P5  │ │
│ └──────────────────────────────────────────┘ │
│                                                │
│ ┌──────────────────────────────────────────┐ │
│ │ Relational Context (RC):                  │ │
│ │ • Object-object relationships             │ │
│ │ • Graph attention networks (GAT)          │ │
│ │ • Edge features: spatial distance + angle │ │
│ └──────────────────────────────────────────┘ │
└────────────────────────────────────────────────┘
                    ↓
┌────────────────────────────────────────────────┐
│ CONTEXT FUSION DECODER                        │
│ • Transformer decoder with context injection  │
│ • Multi-head attention over fused contexts    │
│ • Autoregressive word generation              │
└────────────────────────────────────────────────┘
```

**Strengths**:
- ✅ **Most comprehensive context modeling** (intra + inter + relational)
- ✅ Multi-scale feature pyramid (handles scale variation)
- ✅ Explicit relationship modeling (GAT for object interactions)
- ✅ Best on RSICD (largest dataset): 54.12% BLEU-4
- ✅ Strong spatial reasoning (distance + angle features)

**Weaknesses**:
- ❌ Complex pipeline (3 context modules + fusion)
- ❌ Higher memory consumption (multi-scale + graph)
- ❌ Training complexity (multiple loss functions)
- ❌ Not tested on Sydney dataset

### **3️⃣ PCSFTr: Dual-Domain Attention**
```
┌────────────────────────────────────────────────┐
│ ENCODER: PCMSA Block (Dual Attention)         │
│                                                │
│ ┌──────────────────┐  ┌──────────────────┐   │
│ │ PMSA (Position)  │  │ CMSA (Channel)   │   │
│ │ • Spatial attn   │  │ • Channel attn   │   │
│ │ • Fp ∈ R^(N×C)   │  │ • Fs ∈ R^(C×N)   │   │
│ │ • Q=Fp·Wq        │  │ • Q=K=V = Fs     │   │
│ │ • K=Fp·Wk        │  │ • No projection  │   │
│ │ • V=Fp·Wv        │  │ • hp heads       │   │
│ │ • hc heads       │  │                  │   │
│ └──────────────────┘  └──────────────────┘   │
│           ↓                     ↓              │
│ ┌─────────────────────────────────────────┐  │
│ │ Feature Fusion (FF) Block               │  │
│ │ • Initial: z = P + C                    │  │
│ │ • Local: L(z) = BN(Conv2(ReLU(Conv1)))  │  │
│ │ • Global: G(z) = BN(W2(ReLU(W1(GAP)))) │  │
│ │ • Attention: M(z) = σ(L(z) ⊕ G(z))      │  │
│ │ • Final: Ff = M(z)⊗P + (1-M(z))⊗C       │  │
│ │ • Bottleneck C→C/r→C (reduces params)   │  │
│ └─────────────────────────────────────────┘  │
└────────────────────────────────────────────────┘
                    ↓
┌────────────────────────────────────────────────┐
│ DECODER: Semantic Mask + Cross Attention      │
│ • SMaskMHA: [g^T, Ew] → inject global info    │
│   └─ g = GAP(Fe) (global semantic vector)     │
│ • CrossMHA: Image-text interaction            │
│ • Masked attention prevents future leakage    │
└────────────────────────────────────────────────┘
```

**Strengths**:
- ✅ **Most balanced** position + channel modeling
- ✅ Intelligent fusion (FF block > simple concat)
- ✅ **Most efficient** (Ne=3, Nd=3 layers only)
- ✅ Best on UCM-Captions (78.42% BLEU-4)
- ✅ Scene pre-training (ResNet adaptation)
- ✅ Bottleneck design reduces parameters

**Weaknesses**:
- ❌ **Single-scale weakness** (only ResNet final layer)
- ❌ Sydney dataset underperformance (-13.7% CIDEr vs. best)
- ❌ SPICE lag (misses small object details)
- ❌ No multi-scale fusion like FPN

---

### **4️⃣ TSFE: Two-Stage Sequential Enhancement**
```
┌────────────────────────────────────────────────┐
│ STAGE 1: AMFF (Multi-Scale Foundation)        │
│ • Swin Transformer → {F1, F2, F3, F4}         │
│ • Skip F1, concat F2+F3+F4 (channel dim)      │
│ • SENet: Fs = SENet(F, θ)                     │
│   └─ Adaptive channel attention weights       │
│ • Weighted fusion: Vlocal = w1·F4 + w2·Fs     │
│   └─ w1, w2 trainable parameters              │
│ • Global: Vglobal = GAP(Vlocal)               │
│   └─ Multi-scale scene semantics              │
│                                                │
│ **Fine-Tuning Task**:                         │
│ • Align Vglobal ↔ GloVe(sentence_avg)         │
│ • Loss: smoothL1(Vglobal, GloVe_embeddings)   │
│ • Multi-label approach (avg of all words)     │
└────────────────────────────────────────────────┘
                    ↓
┌────────────────────────────────────────────────┐
│ STAGE 2: LFSE (Positional Relations)          │
│ **Efficient Squeeze-Based Attention**:        │
│ • Horizontal: q^(h) = (1/W)·avg(q) → (H,C)   │
│ • Vertical: q^(v) = (1/H)·avg(q) → (W,C)     │
│ • Attention: Va = Σ softmax(q^(h)T·k^(h))v^(h)│
│            + Σ softmax(q^(v)T·k^(v))v^(v)     │
│ • Complexity: O(H²W²) → O(HW·C) ✅            │
│                                                │
│ **Detail Enhancement**:                       │
│ • Vu = BN(Dwconv[concat(q,k,v)])              │
│   └─ 3×3 depthwise conv captures local details│
│ • Vs = Va × BN(Conv[Vu])                      │
│                                                │
│ **Local Attention Module** (N soft attentions):│
│ • Construct N weighting maps α ∈ R^(N×H×W)    │
│ • α[n,i,j] = exp(α̅)/Σexp(α̅)                  │
│ • V'local = GAP weighted by α                 │
│   └─ Restores long-distance correlations      │
└────────────────────────────────────────────────┘
                    ↓
┌────────────────────────────────────────────────┐
│ FID: Feature Interaction Decoder              │
│ • Attention: at = (V'local^T·W·ht-1)/√d       │
│ • Weighted: vt = softmax(at) * V'local        │
│ • Global fusion: xt = concat[vt, MLP(Vglobal, st-1)]│
│   └─ MLP aligns image/text features           │
│ • LSTM with global context guidance           │
│ • **Continuous embeddings** (no softmax)      │
│ • Dual loss: L1 (word) + L2 (sentence)        │
└────────────────────────────────────────────────┘
```

**Strengths**:
- ✅ **Best on RSICD** (54.86% BLEU-4, +15.7% vs. baseline)
- ✅ **Systematic approach** (multi-scale → positional)
- ✅ **Efficient squeeze attention** (reduces O(H²W²) → O(HW·C))
- ✅ **Sophisticated fine-tuning** (Vglobal ↔ GloVe alignment)
- ✅ Dual detail recovery (conv kernel + local attention)
- ✅ Multi-scale global features

**Weaknesses**:
- ❌ **Mixed performance on small datasets** (Sydney: -1.6% CIDEr)
- ❌ **Two-stage overhead** vs. single-stage methods
- ❌ METEOR lag on RSICD (-3.7% vs. MGTN baseline)
- ❌ Requires separate fine-tuning phase

| **TSFE** | **Squeeze-based** | **O(HW·C)** ✅ | **Efficiency breakthrough** ⭐ |

**Winner (Innovation)**: **PCSFTr** (dual-domain synergy)  
**Winner (Efficiency)**: **TSFE** (squeeze reduces O(H²W²) → O(HW·C))
