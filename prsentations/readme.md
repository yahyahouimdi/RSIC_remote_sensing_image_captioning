# Presentation Collection

This folder contains the presentation files generated during the course of the research project. These presentations were developed based on the study, literature review, architecture analysis, and experimental findings carried out throughout the project.

The content reflects the author's own research direction, technical understanding, and decisions. Some presentation drafts were supported by AI tools such as Claude to help structure ideas and improve wording, but the logic, model selection, narrative flow, scientific choices, and final interpretation were all decided by the researcher.

---

## Project Context

This collection documents the evolution of the work on image captioning and deep learning architectures, especially around the TSFE model and related comparative architectures. It includes presentations on:

- architecture comparison;
- pipeline design and model flow;
- CRSR-based semantic modeling;
- TSFE presentation and proposal refinements;
- enhancement ideas and future improvements.
